# 런대시 SEO 점검

2026년 11월 19일 기준입니다. 운영 사이트 응답, 저장소의 공개 페이지, 새 프로덕션 빌드를 확인했습니다.

## 운영 사이트에서 확인한 내용

| 점검 항목 | 결과 |
| --- | --- |
| 홈, 게임 가이드, 이용약관, 개인정보처리방침 | HTTP 200 응답과 페이지별 제목, 설명, H1, 대표 URL을 확인했습니다. |
| 크롤링 | `robots.txt`에서 크롤링을 허용하고 `sitemap.xml`을 안내합니다. 기존 공개 페이지를 막는 `X-Robots-Tag`는 없었습니다. |
| 기존 사이트맵 | 홈·가이드·이용약관·개인정보처리방침 4개 URL을 제공합니다. |
| 대표 도메인 | HTTP 주소와 `www` 없는 HTTPS 주소는 HTTPS `www.rundash.run`으로 308 리디렉션됩니다. `/guide/`와 `/guide/index.html`은 같은 내용을 제공하고 대표 URL로 `/guide`를 지정합니다. |
| 없는 페이지 | 임의 경로는 HTTP 404를 반환합니다. 이번에 추가한 주제 URL 8개도 현재 운영에서는 404입니다. |
| 홈의 HTML과 브라우저 렌더링 | 초기 HTML에 소개와 가이드 링크가 있었고, React 실행 후에는 로그인 화면과 푸터가 표시됐습니다. 주제별 링크는 기존 운영 버전에 없었습니다. |
| 공유와 사이트 확인 | 홈의 OG 및 X 메타 태그, 공유 JPEG 1200×628, 파비콘, 네이버 확인 태그를 확인했습니다. 네이버 계정의 소유 확인 상태는 별도 조회가 필요합니다. |
| 검색 노출과 성능 | 공개 검색에서 공식 도메인 결과가 확인되지 않았습니다. 소유자 도구의 색인·검색어별 노출 데이터는 확인 범위 밖입니다. 공개 PageSpeed Insights API가 HTTP 429를 반환해 운영 Core Web Vitals 수치는 확보하지 못했습니다. |

공개 `site:` 검색의 출력은 검색엔진의 전체 색인 목록을 제공하지 않습니다. URL 검사에서 실제 색인 상태와 검색엔진이 고른 대표 URL을 확인할 수 있습니다. [Google 사이트 검색 연산자](https://developers.google.com/search/docs/monitor-debug/search-operators/all-search-site) · [네이버 URL 검사](https://searchadvisor.naver.com/guide/url-inspection)

## 빌드와 브라우저 점검

- 주제 8개를 각각 초기 HTML로 제공합니다. 고유한 제목·설명·H1, HTTPS 대표 URL, OG 및 X 공유 태그, 페이지와 일치하는 `WebPage` 구조화 데이터를 확인했습니다. 일반 주제 페이지에는 게임이나 타이머의 실행 스크립트를 로드하지 않습니다. 빌드에서 주제별 HTML은 약 4.1~5.5 kB였습니다.
- 홈의 초기 HTML과 React가 실행된 홈에 같은 주제 링크를 연결했습니다. 공개 게임 가이드와 각 주제 페이지에서도 다른 주제로 이동할 수 있습니다. 링크는 실제 주소가 있는 `a href`입니다. [Google 링크 크롤링 가이드](https://developers.google.com/search/docs/crawling-indexing/links-crawlable)
- 사이트맵에 대표 URL 12개를 등록했습니다. 홈·가이드·새 주제의 수정일을 갱신했습니다. 개발 서버와 프로덕션 미리보기에서 12개 경로의 HTTP 200, 사이트맵·공유 이미지·스타일 응답, 없는 경로의 HTTP 404를 확인했습니다.
- Chrome에서 자바스크립트 활성·비활성 상태의 홈 링크를 확인했습니다. 주제 8개를 320×720과 1280×800에서 열었고 가로 넘침이 없었습니다. 타이머의 시작·일시정지·재개·초기화·집중 후 휴식·4회 집중 후 긴 휴식·탭 복귀 시 시간 보정을 확인했습니다.
- 공백 없는 임시 경로에서 전체 테스트 129개가 통과했습니다. 경로, 사이트맵, 링크와 페이지별 메타데이터를 검사하는 회귀 테스트를 포함합니다.
- 게임 가이드의 레벨과 기본 설정을 현재 게임에 맞췄습니다. 본문의 FAQ를 유지했고 Google이 지원을 종료한 FAQ 검색 기능의 구조화 데이터를 제거했습니다. [Google 검색 문서 변경 내역](https://developers.google.com/search/updates)

## 운영 배포 후 확인할 항목

1. 새 빌드가 운영에 반영되면 주제 URL 8개의 HTTP 200 응답과 운영 사이트맵의 URL 12개를 확인합니다.
2. Google Search Console과 네이버 서치어드바이저의 소유자 계정에서 `https://www.rundash.run/sitemap.xml` 제출 상태를 확인합니다. URL 검사에서 수집·색인 상태와 대표 주소를 확인합니다. [Google Search Console](https://developers.google.com/search/docs/monitor-debug/search-console-start) · [네이버 사이트맵 제출](https://searchadvisor.naver.com/guide/request-feed)
3. 공개된 뒤 페이지별로 검색어·노출·클릭을 확인합니다. 검색량이 큰 단일어와 함께 `러닝 입문`, `친구와 온라인 러닝`, `러닝화 고르는 법`, `공부할 때 켜두는 게임`, `온라인 스터디`, `힐링 러닝 게임`, `뽀모도로 타이머` 같은 구체적인 검색어를 추적합니다. 운영 방문자 데이터가 쌓이면 모바일 Core Web Vitals 보고서도 확인합니다. [Google Search Console 보고서](https://developers.google.com/search/docs/monitor-debug/search-console-start)

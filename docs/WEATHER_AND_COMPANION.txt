Run dash 날씨·활동 구름·초대 조건 업데이트

날씨
- 실제 기상 정보가 아닌 게임 코스 날씨. 위치 권한이나 외부 API 키 불필요.
- 모든 러너가 동일한 UTC 5분 구간에 같은 랜덤 날씨를 공유.
- 맑음 30%, 흐림 20%, 가벼운 비 15%, 가벼운 눈 10%, 폭염 8%, 혹한 6%, 폭우 7%, 폭설 4%.
- 일반 날씨 체력 소모는 기존과 동일.
- 폭염 +40%, 혹한 +35%, 폭우 +30%, 폭설 +45%.
- 추가 배율은 달리는 거리당 체력 소모에만 적용. 일시정지·탈진 회복 중에는 추가 차감 없음.
- 날씨 판: 현재 상태, 온도(°C), 습도(%), 강수 강도, 체력 소모 영향, 다음 변경까지 시간.
- 비/눈은 하나의 파티클 드로우콜로 표시하고, 동작 줄이기 설정을 존중.
- 백그라운드 지연·진행 복구 중에도 지난 날씨 구간별 배율을 같은 방식으로 반영.

활동 구름
- 공개된 위치 또는 수락한 동행 관계의 러너에게 활동 구름 표시.
- 내 활동 구름 공개 체크박스로 공유 중단 가능.
- 기존 구름 표시 버튼은 내 화면의 모든 러너 구름을 켜고 끔.
- 공개하지 않은 활동은 서버 응답에서 null로 처리.

초대
- 들어온 초대는 토스트로 알림. 같은 초대는 반복 알림하지 않음.
- 초대 보기 버튼으로 친구 패널 열기.
- 초대 당시 방장의 기준 페이스와 목표 거리를 카드에 표시.
- 수락은 현재 러닝 결과 저장 → 표시된 페이스/거리의 새 러닝 시작 → 동행 합류를 하나의 DB 트랜잭션으로 처리.
- 새 러닝은 0km부터 시작하며 다른 사람이 이미 달린 거리를 내 기록에 더하지 않음.
- 실패·정원 초과 시 기존 러닝과 기록 변경도 모두 롤백.
- 같은 새 러닝 ID로 재시도해도 이전 기록 중복 저장/XP 중복 지급 없음.
- 초대 당시 러닝 또는 조건이 바뀌면 새 초대 필요.
- 기준 페이스는 맞추지만 체력 저하·회복·날씨로 실제 순간 속도는 달라질 수 있음.

방장 일시정지
- 서버에서 현재 방장만 일시정지/재개 허용.
- 일반 멤버의 버튼과 P 단축키는 비활성화.
- 방장 상태는 기존 약 3초 갱신 주기로 멤버에게 반영.
- 일반 멤버는 방장이 재개할 때까지 대기하거나 러닝 종료 가능.
- 도움말/종료 확인을 열어도 동행 중인 러너의 진행을 임의로 멈추지 않음.
- 방장이 나가면 남은 멤버 중 새 방장을 지정하는 기존 규칙 유지.

서버 적용
- 011까지 적용된 프로젝트에 012_activity_clouds.sql → 013_companion_rules.sql 순서.
- 사용자에게 두 파일을 묶은 rundash-weather-companion-update.sql 전달, 실행 완료 회신 받음.
- 운영 DB 직접 연결 대신 사용자 SQL Editor 실행 방식 사용.

검증
- 자동 테스트 45개 통과, 프로덕션 빌드 통과.
- SQL: 활동 비공개, 다른 계정 수락 차단, 초대 조건 일치, 원자적 롤백, 중복 저장 방지, 방장 권한과 변경, 정원 검증.
- 시뮬레이션: 모든 날씨 범위/확률, 극한 날씨 추가 체력 소모, 정지 중 차감 없음, 날씨 경계를 넘는 지연/복구 일치.
- 로컬 테스트 데이터로 데스크톱 폭설, 모바일 폭우, 활동 구름, 초대 조건 및 토스트에서 패널 열기 확인.
- 실제 운영 두 계정의 초대→수락→방장 일시정지 흐름은 배포 후 확인 필요.
